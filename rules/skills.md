# Skills
> leitor: agente

## Onde ficam

- Todas as skills deste projeto ficam em `skills/`, uma subpasta por
  skill (ex.: `skills/solid/`).
- Cada skill tem um `SKILL.md` próprio (instruções) e pode ter uma
  pasta `references/` com material de apoio.

## Como escolher

- Antes de decidir qual skill usar — ou se alguma se aplica — leia o
  índice em `skills/skills.md`. Esse índice lista as skills
  disponíveis e quando cada uma se aplica.
- Não abra o `SKILL.md` de uma skill específica "no escuro" sem antes
  ter conferido o índice: é o índice que diz qual delas é relevante
  para a tarefa atual.
- Se o índice indicar mais de uma skill aplicável, ou nenhuma, siga o
  critério de precedência do próprio AGENTS.md (na dúvida, pergunte).

## Manutenção

- Ao adicionar, remover ou renomear uma skill em `skills/`, atualize
  `skills/skills.md` no mesmo commit. Índice desatualizado é pior que
  não ter índice.
